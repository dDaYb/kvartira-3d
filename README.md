# 3D-модель квартиры

Страница крутит промежуточную модель в браузере. На сайт попадает файл `model/apartment.glb`. Исходный blend в репозиторий не входит и при выгрузке не перезаписывается.

Потолки в выгрузке скрыты, чтобы комнаты были видны сверху. Это просмотр объёма, не утверждённая отделка и не закупка.

## Как обновить модель

1. Сохранить новую версию blend в `01 Проект квартиры/Актуальный проект`. Оригинал не перезаписывать.
2. Если на сайт должен попасть не тот файл, что указан сейчас, заменить путь в `источник.txt`.
3. Из этой папки выполнить:

```powershell
.\обновить-модель.ps1
```

Скрипт заново соберёт `model/apartment.glb` и `model/info.json`, закоммитит их и отправит на GitHub. Страница GitHub Pages обновится с той же ссылки.

Только собрать файл локально, без отправки:

```powershell
.\обновить-модель.ps1 -Local
```
